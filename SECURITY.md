# Security policy

## Supported versions

| Branch | Supported |
|---|---|
| 19.0 | yes |
| 18.0 | yes |

Fixes go to the newest version of each add-on on the supported branches.

## Reporting a vulnerability

Please report vulnerabilities **privately**, not in a public issue:
use GitHub's *Report a vulnerability* button on the repository's
**Security** tab (private vulnerability reporting).

Include the add-on, its version, the Odoo version, what an attacker can do,
and the steps to reproduce. You will get an answer within five working days.
Please give us a reasonable time to release a fix before you publish
anything.

## Scope

The add-ons in this repository. Vulnerabilities in Odoo itself, in OCA
modules or in APIX's service belong to their own projects.
